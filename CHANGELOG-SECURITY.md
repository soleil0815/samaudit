# Sicherheitsupdates / Security updates

Automatische wöchentliche Sicherheitsupdates: **gleiches Programm, nur neue Paketstände** innerhalb des Unterbaus (Python-Reihe, Debian-Version, Hauptversionen der Pakete). Nummerierung: `<Programmversion>-s<Zähler>`, z. B. `1.9.7-s1`; eine neue Programmversion setzt den Zähler zurück. Programmänderungen stehen im README unter „Neu in …“.

*Automatic weekly security updates: **same program, only newer packages** within the base (Python series, Debian release, major versions of packages). Numbering: `<program version>-s<counter>`; a new program version resets the counter.*
